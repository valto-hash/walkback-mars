# License decision required

The repository is public, but a license for WALKBACK's original source code has not yet been selected by the team. A public GitHub repository is visible to others; without an explicit license, do not assume that others have permission to reuse, modify or redistribute the team's original code.

The 2026 NASA Space Apps Participant Terms state that original solution content must be freely available or licensed as open source under an OSI-compliant license. The terms further state that, if no specific OSI-compliant license is specified, NASA will distribute the original content under Apache 2.0. NASA also states that solutions must include appropriate license documentation.

Before adding a `LICENSE` file:
1. Discuss the choice with all contributors.
2. Confirm that each contributor agrees to the selected license.
3. Add the complete license text at the repository root.
4. Keep third-party licenses and data attribution notices separate and accurate.

NASA terms: https://www.spaceappschallenge.org/legal/

Do not treat Three.js's MIT license as the license for WALKBACK.
