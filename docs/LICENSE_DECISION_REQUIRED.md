# License decision required

The repository is public, but the team has not selected a license for WALKBACK's original source code. Public visibility alone is not an open-source license. Do not assume the Three.js MIT license applies to this project.

The NASA Space Apps 2026 Participant Terms require original solution content to be freely available or licensed under an OSI-compliant open-source license, and state that if no specific OSI-compliant license is selected, NASA will distribute original solution content under Apache 2.0. Review the current participant terms: https://www.spaceappschallenge.org/legal/ .

Before adding a root `LICENSE` file:

1. Discuss the choice with all contributors.
2. Confirm that every contributor has the authority to license their contribution and agrees to the selected license.
3. Add the complete license text at the repository root.
4. Keep third-party software and data notices in `CREDITS.md`.

Do not leave the submission form's license field blank without checking the current instructions.
